# Eclipse v2.0.3

- Faster Discord sharing: unchanged clips under 20 MB copy without re-encoding; larger clips use adaptive quality and resolution.
- Clip preparation stays visible when switching between the preview and library.
- More reliable recording recovery, clearer audio settings and improved default capture options.
- Added real-time friend chat, message sounds, notifications and per-friend muting.
- Reduced Firebase reads and writes with shared listeners, caching and fewer redundant updates.
- Added three customizable Quick Actions with sidebar, header and title-bar placement.
- Added game-specific crosshairs for VALORANT, Fortnite and CS2, plus CS2 session statistics.
- Added performance-overlay mirroring and a toggle hotkey; improved overlay editing and responsiveness.
- Unified dropdown styling and animations, with faster cover-loading feedback and improved translations.
- Improved Discord Rich Presence with proper game icons, optional version display, clearer Steam download status and a GitHub button.
